# tiktok

Guide for installing LiveContainer with iLoader and importing your own IPA file.

## Official Downloads

iLoader:

- Website: https://iloader.app
- GitHub: https://github.com/nab138/iloader

These are the only official sources for iLoader. Avoid downloading it from third-party websites.

## Requirements

- iPhone or iPad
- Windows, macOS, or Linux computer
- USB cable
- Apple ID
- Internet connection
- iLoader

iLoader supports Windows, macOS, and Linux and can automatically install SideStore or LiveContainer + SideStore.

## Step 1: Download iLoader

Download iLoader from:

https://iloader.app

Install it on your computer and launch the application. iLoader is free and open source.

## Step 2: Connect Your Device

Connect your iPhone or iPad to your computer using a USB cable.

If prompted:

1. Unlock your device.
2. Tap **Trust This Computer**.
3. Enter your passcode.

Your device should now appear inside iLoader.

## Step 3: Sign Into iLoader

Open iLoader and sign in using your Apple ID.

Notes:

- The Apple ID does not need to match the Apple ID currently signed into the device.
- Credentials are case-sensitive.
- A free Apple ID is sufficient.

## Step 4: Install LiveContainer + SideStore

Inside iLoader:

1. Select your device.
2. Choose **Install LiveContainer + SideStore**.
3. Start the installation process.
4. Wait for iLoader to complete setup.

iLoader will handle certificate setup and installation automatically.

## Step 5: Trust the Developer Profile

On your iPhone or iPad:

1. Open **Settings**.
2. Go to **General**.
3. Open **VPN & Device Management**.
4. Under **Developer App**, select your Apple ID.
5. Tap **Trust**.
6. Confirm the trust prompt.

After trusting the profile, LiveContainer should launch normally.

## Step 6: Open SideStore

Launch LiveContainer.

Tap the SideStore icon in the top-left corner. This will open SideStore.

## Step 7: Sign Into SideStore

Inside SideStore:

1. Open **Settings**.
2. Sign in with the same Apple ID used in iLoader.
3. Allow SideStore to generate a development certificate.

Wait until the process completes successfully.

## Step 8: Import the Certificate

Close SideStore and reopen LiveContainer.

Navigate to:

**Settings -> Import Certificate From SideStore**

Wait for the certificate import process to finish. Once complete, LiveContainer is fully configured.

## Step 9: Import an IPA

This repository does not host IPA files. Use your own legally obtained IPA file.

To import an application:

1. Open LiveContainer.
2. Tap the **+** button.
3. Select the IPA file you want to import.
Download My custom IPA here: https://limewire.com/d/wkNcM#fnLiBAw8X1

4. Wait for the import to finish.
5. Launch the app directly from LiveContainer.
6. To add it to the Home Screen, hold the app icon, choose **Add to Home Screen**, then create the app clip.
